Como funcionam os avisos

Quando um programa cadastrado publicar um episódio novo no feed, o DGX poderá enviar uma notificação mesmo que o aplicativo esteja fechado, após você ativar Web Push em Avisos.

Nem todo podcast publicado no Spotify disponibiliza um RSS público. Nesses casos, podemos acompanhar os programas disponíveis na API do Spotify após autorização, mas a verificação automática pelo servidor depende de outra fonte ou autorização persistente.

Mais vozes brasileiras
Motor de voz independente do Android · experimental

Três locutores com timbres próprios, sem trocar o idioma: uma voz feminina e duas masculinas. O texto é transformado em áudio no próprio dispositivo.

Atenção ao consumo de internet: é necessário baixar um modelo de aproximadamente 295 MB na primeira ativação. Recomendamos Wi-Fi. O modelo pode precisar ser baixado novamente se o cache do navegador for apagado.

Nenhum modelo de voz adicional foi carregado.

Voz padrão do Android

O DGX vai listar os locutores disponibilizados pelo Android. Mudar velocidade não altera a identidade da voz.

Personalizar o que será lido

A leitura usa a voz do navegador. Pode ser interrompida com a tela bloqueada ou se o Android suspender a página. Não há gravação de áudio.

Verificando conexão...

Entendo pedidos como “toque Evidências”, “músicas de Skank”, “playlist de rock”, “próxima” e “pause”. Se sua conta Spotify Premium estiver autorizada, tento tocar na reprodução ativa do celular. Sem conexão, abro a busca no Spotify.

Abrir busca no Spotify ↗

No painel Spotify for Developers, crie um aplicativo Web API e cadastre exatamente este endereço de retorno: https://dgx-meu-dia.onrender.com/. É necessário Spotify Premium para controlar a reprodução pela API.

Por segurança, configure a conta parado, antes de dirigir. A versão web não oferece escuta contínua garantida nem comandos com a tela bloqueada.
